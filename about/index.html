About

I help Canada-first WooCommerce stores make practical performance and SEO decisions without breaking checkout or shipping risky changes.

I’m an independent consultant focused on Core Web Vitals, TTFB, checkout reliability, and GA4-measured impact. My work is intentionally production-safe: baseline first, then staged fixes with clear rollback options.

My default: measure → prioritize → stage → validate checkout → deploy → monitor.

No hype. No “magic plugins”. No surprises in production.

What I focus on

  • TTFB + server bottlenecks: caching boundaries, hosting constraints, database hotspots
  • Core Web Vitals: LCP/INP/CLS improvements with real-world impact in mind
  • Checkout reliability: preventing regressions from caching, scripts, or plugin conflicts
  • Product page SEO + speed: template-level performance + SEO fundamentals that support revenue
  • Measurement: GA4 events and KPIs to validate what actually moved

How I work

Most projects start with an audit. It prevents random fixes and gives you a clean roadmap: quick wins first, then higher-impact work that’s safe to ship.

Audit deliverables (typical):

  • Baseline CWV/TTFB + bottleneck map
  • Checkout risk checklist (cache boundaries + fragments)
  • Prioritized fix plan (quick wins → big wins)
  • Tracking/measurement plan (GA4 events + KPIs)

Who I work with

  • WooCommerce store owners who need speed without breaking revenue flows
  • Teams dealing with slow product templates or plugin conflicts
  • Operators who want clear priorities instead of endless “optimization”
  • Founders who value documentation and measurable outcomes

What I don’t do

  • No fear-based marketing
  • No “guaranteed results” claims
  • No platform evangelism (tradeoffs first)
  • No unnecessary complexity or unsafe production changes
